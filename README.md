# 风格图谱 Style Atlas

音乐风格学习网站（IDM 起步）：学习手册、技巧索引、曲目库、学习路线、卡点与对策。

手机打开：<https://kirudore-junjun.github.io/fengge/>，在 Safari 里「分享 → 添加到主屏幕」即可像 app 一样使用。

- 数据文件的格式和更新方法见 `data/README.md`。
- 在 GitHub Pages 上音频直接用 `fetch` 读取，不需要 `.b64.js` 副本；MIDI 已还原成 `.mid` 文件。
- `audio/tom-quibble/full-320.mp3`（整首，9.6 MB）暂未上传。
